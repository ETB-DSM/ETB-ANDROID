# Compose 화면 구현

## 개요

HTML 프로토타입(`AI-Cane 앱 프로토타입.html`)을 기준으로 13개 화면을 Jetpack Compose로 구현한다.
디자인 시스템은 `DESIGN.md`(Uber 스타일), 아키텍처는 `TRD.md`(MVVM + Clean Architecture)를 따른다.

### 공통 컴포넌트 명세

#### PillButton

```kotlin
PillButton(
  text: String,
  onClick: () -> Unit,
  modifier: Modifier = Modifier,
  variant: PillButtonVariant = Primary,   // Primary | Secondary | Subtle | Danger
  enabled: Boolean = true,
  isLoading: Boolean = false
)
```

- Primary: background=Ink, text=OnInk, height=56dp, radius=999dp
- Secondary: background=Canvas, border=SurfacePressed, text=Ink
- Subtle: background=CanvasSoft, text=Ink
- Danger: background=Canvas, border=SurfacePressed, text=Error

#### AiCaneTextField

```kotlin
AiCaneTextField(
  value: String,
  onValueChange: (String) -> Unit,
  label: String,
  modifier: Modifier = Modifier,
  placeholder: String = "",
  keyboardType: KeyboardType = Text,
  isError: Boolean = false,
  errorMessage: String = "",
  caption: String = ""
)
```

- height: 64dp, background: CanvasSoft, radius: 8dp
- error border: Error(#E53E3E)

#### BackButton

```kotlin
BackButton(
  onClick: () -> Unit,
  isDark: Boolean = false  // true → InkElevated bg + white icon (마이페이지/길안내용)
)
```

- size: 48dp × 48dp, radius: 9999dp
- light: background=CanvasSoft, icon=Ink
- dark: background=InkElevated, icon=OnInk

## 화면별 구현 기준

### SplashScreen
- 검정 배경 전체
- 중앙 상단 42%: 세 겹 ringOut 애니메이션 (Compose infiniteTransition + scale/alpha)
- 중앙 하단 62%: "AI-Cane" + "걸음마다, 함께 읽는 길" 슬라이드 인
- LaunchedEffect로 1.5초 후 자동 이동 (토큰 존재 시 DestinationList, 없으면 Login)

### SignupScreen
- 상태: step = Email | Name | Password (3단계)
- 상단: BackButton + 진행 점 3개 (활성: 28dp wide pill, 비활성: 8dp circle)
- 각 step 진입 시 drop 애니메이션 (AnimatedContent)
- 이메일 입력 → 다음 → 이름 입력 → 다음 → 비밀번호 입력 → 회원가입

### NavigationScreen
- 상단 320dp 블랙 밴드: action 텍스트(DisplayXL white) + 거리(BodyLg muted) + 진동 힌트 pill
- 하단: 목적지명 + 길안내 상태 + 디바이스 상태 카드(배터리+연결) + 다음 안내 목록 + 종료 버튼
- navBg: straight/prepare/turn=#000000, reroute=#282828

## 데이터 흐름

화면은 모두 ViewModel-less Preview 가능 상태로 구현 (상태를 람다로 주입).
실제 ViewModel 연결은 TRD.md의 Domain/Data 레이어 구현 이후 진행.

## 완료 기준

- 13개 화면이 NavGraph로 연결되어 에뮬레이터에서 전체 플로우 탐색 가능
- DESIGN.md 토큰 (색상, 타이포, 간격)이 HTML 프로토타입과 시각적으로 일치
- 최소 터치 타깃 48dp 준수
- Pretendard 폰트 적용
