# UI 디자인 싱크 작업 문서

**작업 일자:** 2026-08-25  
**브랜치:** `feat/ui-design-sync`  
**기준:** `/home/minsu/다운로드/AI-Cane 앱 프로토타입.html` (Framer 번들 프로토타입)

## 개요

프로토타입과 현재 앱 UI 간의 차이를 분석하여 11개 화면 및 컴포넌트를 수정했다.  
데이터 레이어는 사용자 이름/이메일 표시에 필요한 최소 범위만 확장했다.

---

## 데이터 레이어 변경

| 파일 | 변경 내용 |
|------|----------|
| `data/local/TokenStorage.kt` | `userName`, `userEmail` 프로퍼티 추가 (EncryptedSharedPreferences) |
| `domain/repository/AuthRepository.kt` | `fun getUserInfo(): Pair<String, String>` 인터페이스 추가 |
| `data/repository/AuthRepositoryImpl.kt` | signup/login 시 userName/userEmail 캐시; `getUserInfo()` 구현 |
| `domain/usecase/auth/GetUserInfoUseCase.kt` | 신규 생성 (non-suspend, Pair 반환) |
| `presentation/auth/SignupViewModel.kt` | `LoginWithGoogleUseCase` 의존성 추가, `loginWithGoogle()`, `setError()`, `NavigateComplete` 이벤트 추가 |
| `presentation/mypage/MypageViewModel.kt` | `GetUserInfoUseCase` 의존성 추가, UiState에 `userName`/`userEmail` 추가 |
| `presentation/destination/DestinationListViewModel.kt` | `GetUserInfoUseCase` 의존성 추가, UiState에 `userInitial` 추가 |
| `nav/NavGraph.kt` | `SignupEvent.NavigateComplete` → `Screen.Device` 라우팅 추가 |

## UI 변경 사항

### AiCaneTextField
- `compact: Boolean = false` 파라미터 추가
- `compact=true` 시 높이 56dp (기존 64dp)

### LoginScreen
- 링 아이콘 (44dp, CircleShape border 5dp Ink)
- "AI-Cane" 타이틀 (DisplayLg)
- 입력 필드를 CanvasSoft 카드(16dp radius, 24dp padding)로 묶음
- "또는" 구분선 + Google 로그인 버튼
- 단일 파란색 링크: "계정이 없으신가요? 회원가입"

### SignupScreen
- Password 단계: `비밀번호 확인` 필드 추가, 불일치 시 인라인 에러
- Name 단계: 보호자 표시 관련 캡션 추가
- Email 단계 하단: "또는" 구분선 + Google 가입 버튼

### VerifyScreen
- 수직 가운데 정렬 (Arrangement.Center)
- 이메일 pill (CanvasSoft, RoundedCornerShape(999.dp))
- OTP 6박스 그리드 (숨겨진 BasicTextField + repeat(6) Box 시각화)

### DeviceScreen
- 눈물방울 아이콘: 56dp Box, `RoundedCornerShape(999,999,999,2)`, border 5dp Ink, rotate(-45°)
- 전체 중앙 정렬 (Arrangement.Center + CenterHorizontally)
- 캡션: "지팡이 손잡이 안쪽 라벨에서 확인할 수 있습니다"

### NavigationEndScreen
- 배경: Canvas (흰색)
- 96dp Ink 원 + "✓" 흰색 텍스트
- "홈으로" Primary 버튼

### MypageScreen
- 헤더 (Ink 배경):
  - BackButton + "마이페이지" 타이틀
  - 이니셜 원 (60dp, border 3dp OnInk) + 이름(DisplayMd)/이메일(BodySm)
  - Status chips: 지팡이 상태 + 보호자 상태 (InkElevated 배경)

### DestinationListScreen
- 마이페이지 버튼: `Icons.Default.Person` → 이니셜 텍스트 Box
- 목록 배경: CanvasSofter
- 카드 배경: Canvas(흰색) + "길안내 시작" 텍스트 버튼
- 힌트 텍스트 추가

### SearchScreen
- 헤더: BackButton + "목적지 검색" (DisplaySm)
- 검색 바를 헤더 아래로 분리
- 검색 아이콘: 18dp CircleShape 아웃라인 (border 2dp TextBody)
- "취소" 텍스트 제거

### DestinationRegScreen
- 타이틀: "목적지 저장" → "목적지 확인"
- 상단 검정 카드: 장소명(DisplaySm/OnInk) + 주소(BodySm/TextMute) + 좌표 chip(InkElevated) + "변경" 버튼
- 비활성화 주소/좌표 필드 제거

### NavigationScreen
- 햅틱 pill 배경: `OnInk.copy(alpha=0.15f)` → `InkElevated`
- 8dp 흰색 맥박 dot (alpha 0.25↔1 무한 애니메이션, 550ms) 추가
