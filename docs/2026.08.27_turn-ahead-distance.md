# 직진 중 "다음 회전까지 거리" 안내 추가

작성일: 2026.08.27

## 배경 / 문제

현재 화면은 직진 중일 때 큰 숫자로 **목적지까지 거리**(예: 49609m)만 보여주고,
"몇 m 더 직진하면 회전하는지"는 알려주지 않는다.

원인:
- `ActionCalculator`는 회전 지점 **20m 이내**에 들어가야만 `PREPARE_LEFT/RIGHT`로
  `"Nm 앞 좌회전"`을 만든다. 그 전 긴 직진 구간에는 "다음 회전까지 거리"를 계산·표시하는
  로직이 없다.
- 화면(`NavigationScreen`)의 큰 숫자는 `instruction.distanceMeters` 하나뿐이라,
  직진 시 그 값이 목적지 거리(또는 다음 점까지 거리)로 표시된다.

즉 기능 자체가 없어서 안 뜬다(버그 아님). 본 문서는 **직진 중에도 "다음 회전까지 N m + 회전 방향"**
을 상시 계산·표시하는 기능을 추가한다.

## 전제 (의존)

- **PR #13 (`fix/route-linestring-parsing`)**: "다음 회전까지 거리"를 경로를 따라 누적으로
  정확히 재려면 촘촘한 경로점이 필요하다. Point만 있으면 직선 근사가 커진다.
- **PR #14 (`fix/offroute-detection`)**: 본 작업은 `ActionCalculator.calculate`를 크게
  수정하므로, #14와 같은 함수를 건드린다. **#14 병합 후 그 위에서 작업**하는 것을 권장한다.
  (충돌 방지)

## 상세 설계

### 1. 계산 결과 모델 확장

`ActionCalculator.calculate`의 반환을 `Pair<NavigationAction, Double>` →
`NavigationGuidance`로 확장한다.

```kotlin
data class NavigationGuidance(
    val action: NavigationAction,
    val distanceToDest: Double,        // 목적지까지 직선거리(m)
    val nextTurnType: TurnType?,       // 다음 회전 방향 (없으면 null)
    val distanceToNextTurn: Double?,   // 경로를 따라 다음 회전점까지 거리(m), 없으면 null
)
```

### 2. 다음 회전까지 거리(경로 누적) 계산

`calculate` 내부:
```kotlin
val currentIdx = steps.indices.minByOrNull { haversine(lat, lng, steps[it].latitude, steps[it].longitude) }
val nextTurnIdx = (currentIdx + 1 until steps.size).firstOrNull { steps[it].turnType != TurnType.STRAIGHT }

val (nextTurnType, distanceToNextTurn) = if (nextTurnIdx == null) {
    null to null
} else {
    var d = haversine(lat, lng, steps[currentIdx].latitude, steps[currentIdx].longitude)
    for (i in currentIdx until nextTurnIdx) {
        d += haversine(steps[i].latitude, steps[i].longitude, steps[i + 1].latitude, steps[i + 1].longitude)
    }
    steps[nextTurnIdx].turnType to d
}
```
- 사용자→현재점 오프셋 + 현재점~회전점 구간 길이 합. PR #13의 촘촘한 점이 있으면 실제 경로 길이에 근접.
- 회전이 더 없으면(목적지 직전) 둘 다 null → UI는 목적지 거리만 표시.

`action`(STRAIGHT/PREPARE_*/LEFT/RIGHT/ARRIVED/REROUTE) 판정 로직은 기존 유지.
`ARRIVED/REROUTE/steps 없음` 등에서는 `nextTurnType/distanceToNextTurn = null`.

### 3. 도메인 모델 확장 (UI 전용 필드)

```kotlin
data class NavigationInstruction(
    val sessionId: String,
    val action: NavigationAction,
    val distanceMeters: Double,             // 목적지까지 남은 거리 (카드 "N m 남음"에 사용)
    val message: String,
    val nextTurnType: TurnType? = null,     // UI 표시용, 서버 전송 안 함
    val distanceToNextTurn: Double? = null, // UI 표시용, 서버 전송 안 함
)
```
- `distanceMeters`는 "목적지까지 남은 거리"로 의미를 통일한다(= `distanceToDest`).
- 신규 두 필드는 UI에서만 쓰며, `NavigationRepositoryImpl.createInstruction`은 기존대로
  `action/distanceMeters/message`만 서버로 보낸다.

### 4. NavigationService 매핑

```kotlin
val g = actionCalculator.calculate(...)   // NavigationGuidance
val instruction = NavigationInstruction(
    sessionId          = config.sessionId,
    action             = g.action,
    distanceMeters     = g.distanceToDest,
    message            = g.action.toKoreanMessage(g.distanceToNextTurn, g.nextTurnType),
    nextTurnType       = g.nextTurnType,
    distanceToNextTurn = g.distanceToNextTurn,
)
```
`toKoreanMessage` 확장: 직진이면서 다음 회전이 있으면 `"820m 후 좌회전"`,
회전이 없으면 `"직진"`. (기존 PREPARE/LEFT/RIGHT/ARRIVED/REROUTE 문구는 유지)

### 5. NavigationScreen 표시

- 큰 라벨: `action.toLabel()` (예: "직진") — 유지
- 큰 숫자: **다음 회전까지 거리 우선**
  ```kotlin
  val bigDistance = instruction.distanceToNextTurn?.let { "${it.toInt()}m" }
      ?: "${instruction.distanceMeters.toInt()}m"
  ```
- 보조 라인(신규): 다음 회전 방향
  ```kotlin
  val turnHint = instruction.nextTurnType?.let {
      when (it) { TurnType.LEFT -> "좌회전 예정"; TurnType.RIGHT -> "우회전 예정"; else -> null }
  }
  ```
  → "직진 / 820m / 좌회전 예정" 형태로 노출.
- 하단 카드: `"목적지까지 ${instruction.distanceMeters.toInt()}m 남음"` (목적지 거리로 일관)

## 테스트 방법
1. 실제 경로 위에서 직진 중일 때, 큰 숫자가 **다음 회전까지 거리**로 바뀌고 "좌/우회전 예정"이 뜨는지.
2. 회전 지점에 접근할수록 그 거리가 줄어드는지.
3. 마지막 회전 이후(목적지 직전)에는 회전 안내가 사라지고 목적지 거리만 남는지.
4. 하단 카드의 "N m 남음"이 항상 목적지까지 거리인지.
